# Task-to-Story Converter

## 🎯 Purpose / Overview

Transformar tarefas dispersas em uma story com narrativa única: objetivo, escopo, critérios de aceitação e plano mínimo.

## ⏱️ When to Use / Triggers

## 🧩 Implementation / How to Use

1) Coletar as tasks/inputs

2) Agrupar por tema e dependência

3) Escrever a story

4) Definir escopo

5) Escrever AC

6) Propor tasks derivadas
